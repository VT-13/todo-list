# To-do list

A small command-line to-do list. Tasks are saved in `tasks.json` beside the script.

Requires Python 3. No packages to install.

```sh
python3 todo.py add "Finish homework"
python3 todo.py add "Go for a walk"
python3 todo.py list
python3 todo.py done 1
python3 todo.py remove 2
```

Use the task ID shown by `list` when completing or removing a task.
